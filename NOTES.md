# Куда положить эти файлы

Скопируй `lib/` поверх своей папки `lib/` в проекте (замени `home_screen.dart`,
добавь остальные), и добавь строчку `geolocator` в `pubspec.yaml` (см. файл
`pubspec.yaml` в этом архиве — просто добавь `geolocator: ^13.0.1` в свой,
если у тебя уже есть другие зависимости).

Дальше:

```
flutter pub get
```

## iOS: разрешение на геолокацию

В `ios/Runner/Info.plist` добавь (иначе приложение крашнется при первом
запросе геолокации на iOS):

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Приложению нужна геолокация, чтобы посчитать расстояние до выбранного города</string>
```

## Стиль iOS

Приложение теперь целиком на Cupertino-виджетах (`CupertinoApp`,
`CupertinoPageScaffold`, `CupertinoNavigationBar`, `CupertinoListTile`,
`CupertinoSearchTextField` и т.д.) вместо Material — это даёт нативный шрифт
(San Francisco), нативную анимацию свайпа назад, группированные списки как
в Настройках iOS. Если бы оставили Material — приложение бы запустилось на
iOS и работало, но выглядело бы "по-андроидовски" (риппл при нажатии,
неродной шрифт, не тот back-жест).

`CupertinoListTile` и `CupertinoListSection` появились в не самой старой
версии Flutter — если при сборке ругается, что их нет, сделай
`flutter upgrade`.

## Что добавилось по последнему запросу

- Заголовок "How far am I from..." крупным шрифтом сверху по центру.
- Внизу экрана — текущие координаты пользователя в формате
  "51.2194° N, 4.4025° E" (см. `utils/coordinate_formatter.dart"). Пока
  геолокация грузится — там написано "Locating…", если не получилось —
  "Location unavailable".

## Что уже сделано

- `models/place.dart` — модель "места" (город с lat/lon, либо небесное тело
  с фиксированным средним расстоянием).
- `models/distance_unit.dart` — модель единицы измерения.
- `data/units_data.dart` — все единицы: метрические (мм, см, м, км),
  имперские (in, ft, yd, mi), морская миля, и инженерные/астрономические
  (световая секунда, световая минута, а.е., световой год, парсек).
- `data/cities_data.dart` — стартовый список из ~195 крупных городов
  (координаты). Внутри файла — комментарий, как расширить до 1000 (взять
  готовую базу SimpleMaps World Cities или GeoNames и сконвертировать в
  такой же формат `Place(...)`). Вручную честно наковырять 1000 точных
  координат я не стал — риск наврать в цифрах слишком велик.
- `data/celestial_data.dart` — Луна, Солнце, все планеты, Плутон, Проксима
  Центавра и туманность/галактика Андромеды для проверки очень больших
  чисел. Расстояния до планет — усреднённые (не живая эфемерида), это
  явно прокомментировано в файле.
- `services/location_service.dart` — получение геопозиции пользователя
  (пакет `geolocator`), с обработкой отказа в разрешении.
- `services/distance_service.dart` — расстояние по формуле гаверсинуса для
  городов, фиксированное значение для планет.
- `utils/number_formatter.dart` — форматирование числа: пробелы между
  тысячами ("9 387"), а для очень больших/маленьких значений — вид
  "1.23 × 10⁷" (настоящая надстрочная степень, не текстом).
- `screens/city_picker_screen.dart` — экран выбора города/планеты с
  поиском.
- `screens/unit_picker_screen.dart` — экран выбора единицы измерения,
  сгруппированные по системам.
- `screens/home_screen.dart` — главный экран, всё связано вместе.

## Что стоит доделать самому

- Расширить `cities_data.dart` до 1000 городов (см. комментарий в файле).
- Проверить/подправить точность средних расстояний до планет под свой вкус
  (сейчас это упрощённая модель "разница средних радиусов орбит").
- Возможно, добавить кэширование последней геопозиции, чтобы не ждать GPS
  при каждом открытии.
